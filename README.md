Entry for [One Emoji, One Smile on make.fun](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

A program that writes exactly one emoji — the warmest one a stranger would
smile at — to `/output/entry.txt`. No words, no caption, no explanation.

Run with Python 3.13: `python3 main.py`. No network, no dependencies.
